# UI 对标与设计规范

## 1. 主流软件设计要素对标

| 产品 | 可借鉴 | 刻意避免 |
|------|--------|----------|
| 东方财富 | 红涨绿跌、报价条信息密度、多 Tab 研究 | 过度广告位、杂乱入口 |
| 同花顺 | 行业/概念标签、技术信号色块 | 桌面端过密信息墙 |
| 雪球 | 消息时间线、观点摘要卡片（仅交互区） | 社交噪音喧宾夺主 |
| TradingView | K线工具栏、指标切换、清晰层级 | 过度暗黑霓虹风 |

## 2. 视觉方向（本产品）

- **品牌名**：研盘 AShare Lab（首屏品牌级呈现）
- **色彩**：深青墨底 `#0B1C24` + 琥珀强调 `#E8A838` + 红涨 `#E53935` / 绿跌 `#26A69A`
- **字体**：Web 使用「IBM Plex Sans」+「Noto Serif SC」；避免 Inter/Roboto/系统默认堆栈
- **背景**：墨绿径向渐变 + 细网格纹理，非纯色平板
- **图表**：全宽 K 线作为研究页视觉锚点，非圆角小卡片拼贴
- **卡片**：默认不用；仅搜索框、Tab、可点击结论区保留轻量容器

## 3. 信息架构

### Web

1. **落地/搜索页**：品牌 + 一句价值主张 + 搜索 CTA + 全出血盘面氛围图/抽象行情纹理
2. **研究页**：顶部报价条 → 全宽 K线 → Tab（盘面/基本面/行业/消息/情绪/结论）

### Android（原生，非 WebView）

1. **Kotlin + Jetpack Compose** 原生页面（搜索 / 研究 / Tab / 结论）
2. **MPAndroidChart** 原生 K 线（`AndroidView` 嵌入 Compose）
3. Retrofit 直连同一套 REST API
4. 启动 → 搜索 → 研究：报价头 + ScrollableTabRow 分区 + 结论页

## 4. 动效（至少 3 处）

1. 搜索页品牌字轻微上浮淡入
2. 报价涨跌数字闪色过渡
3. Tab/结论区切换淡入

## 5. 中国行情惯例

- **红涨绿跌**（与欧美相反）
- 价格保留 2 位小数；成交额用「万/亿」缩写
- 涨跌幅旁附涨跌额

## 6. 无障碍与辨识

- 涨跌同时用颜色 + 箭头/符号，不只靠颜色
- 关键按钮最小点击区域 44dp
- 结论区用语义色条（偏多/中性/偏空）
