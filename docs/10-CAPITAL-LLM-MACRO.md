# 筹码资金 · 宏观驱动 · LLM 深度研判

## 目标

以「江淮汽车」类个股为例：在低位筹码、催化拉升、突发负面冲击后，判断资本是继续做多还是借舆论出货；并叠加美联储/地缘等宏观驱动。规则引擎不够时，启用用户自备 LLM。

## 规则引擎（无需 LLM）

1. **筹码估计**：长周期 K 线挖坑低点 + 坑后放量区间 VWAP → 活动成本带；对照历史高位（定增压力区）。
2. **事件抽取**：定增、合作/交付催化、刹车/调查等负面、业绩关键词。
3. **量价阶段**：连续放量拉升 / 放量下跌等。
4. **主力资金**：东财资金流；「上涨日主力净流出」计为派发特征。
5. **舆情结构**：高热 + 标题偏空 → 争议中诱多/接盘风险。
6. **出逃分 vs 拉升分**：合成 `capital_exit` / `plan_disrupted_watch_exit` 等结论。

逻辑要点：负面冲击下「对业绩完全无影响」概率极低；若此前已有低位筹码浮盈 + 放量拉升 + 舆论高潮，则更倾向**出货/出逃窗口**而非新一轮主升。

## 宏观采集

- 东财要闻检索：美联储、地缘、降息、战争、关税等
- 新浪滚动兜底
- 输出 `regime`（避险/风险偏好/中性）与 `risk_score`

## LLM（可选）

在项目根或 `backend/.env` 配置（勿提交）：

```bash
cp .env.example .env
# 编辑 LLM_API_KEY / LLM_BASE_URL / LLM_MODEL
```

兼容 OpenAI Chat Completions。未配置时研究流程仍完整，AI 步骤显示「未配置」。

- `GET /api/v1/macro/drivers`
- `GET /api/v1/llm/status`
