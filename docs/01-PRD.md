# A股智能研究系统 — 产品需求文档 (PRD)

## 1. 产品定位

面向个人投资者与研究员的 **A股个股研究工作台**：输入股票代码或名称，系统聚合盘面、基本面、行业、消息与情绪，输出可执行的操作思路与走势研判。

对标产品：东方财富、同花顺、雪球（研究深度）+ TradingView（图表体验）。

## 2. 目标用户

| 角色 | 诉求 |
|------|------|
| 短线交易者 | 快速看盘、情绪、技术信号 |
| 波段投资者 | K线结构、行业景气、消息催化 |
| 基本面研究者 | 产品/业务、财务摘要、同业对比 |

## 3. 核心用户故事

1. 作为用户，我输入「600519」或「贵州茅台」，系统识别并进入研究页。
2. 作为用户，我在一个页面看到报价、K线、指标、行业、消息、情绪摘要。
3. 作为用户，我能看到系统给出的操作思路（观望/逢低/减仓等）与短中期走势预测区间。
4. 作为用户，我可在 Web 与 Android 使用同等核心能力。

## 4. 功能范围（MVP → 完整）

### 4.1 已纳入本期

- [x] 股票搜索与自动补全
- [x] 盘面：最新价、涨跌、成交额、换手、振幅、量比等
- [x] K线（日/周）+ MA/MACD/RSI/布林带
- [x] 短/中期买卖点（同周期买卖成对，跨周期独立；图表分色分形）
- [x] 产品/业务摘要与概念标签
- [x] 所属行业与同业对比
- [x] 消息面时间线（公告/新闻聚合摘要）
- [x] 市场情绪评分（资金、涨跌幅分布、波动）
- [x] 综合研报：操作思路 + 走势预测
- [x] Web 端研究仪表盘
- [x] Android 原生客户端（Compose）
- [x] 一键启停、Docker 一键部署
- [x] 国内低成本云部署方案文档

### 4.2 明确不做（本期）

- 实盘交易下单
- 付费 Level-2 行情
- 用户账户体系 / 自选云同步（可后续迭代）
- AI 大模型实时解读（预留接口）

## 5. 非功能需求

| 项 | 指标 |
|----|------|
| API 响应（缓存命中） | P95 < 800ms |
| 首次完整分析（冷启动） | < 15s（依赖数据源） |
| Web 首屏 | < 3s（国内节点） |
| Android 冷启动到搜索页 | < 2s |
| 可用性 | 数据源失败时降级为演示/缓存数据并标注 |

## 6. 合规与免责

系统输出仅为研究辅助，不构成投资建议。界面与报告页必须展示免责声明。

## 7. 验收标准

1. 文档齐全且与实现一致。
2. 输入有效 A 股代码可出完整研究报告。
3. Web/Android 均可完成「搜索 → 分析 → 查看图表与结论」路径。
4. `scripts/start.sh` / `stop.sh` 可用；`deploy/` 支持一键 Docker 部署。
5. 自动化测试覆盖核心 API；有 Web/Android 模拟用户测试记录。
