# 买卖点规则（短/中期）

## 1. 周期定义（落地口径）

| 周期 | 代码 | 持仓语义 | 信号窗口 | 主确认指标 |
|------|------|----------|----------|------------|
| 短期 | `short` | 约 **5–20 个交易日** | 局部 5/10 日结构 | MA5/MA10 金叉死叉 + RSI 拐点 + 放量 |
| 中期 | `medium` | 约 **20–60 个交易日** | 局部 20/60 日结构 | MA20/MA60 金叉死叉 + 布林回归 + MACD 柱转向 |

不同周期**相互独立**：短期买点不必等中期买点；可交错出现。

## 2. 成对约束（硬规则）

1. **同一周期内**：必须 `buy → sell` 成对；未平仓的买点在序列结束时用**最后一根 K 线**强制配对卖点（标记 `forced_close: true`）。
2. **禁止**同一周期出现 `buy, buy` 或孤立 `sell`。
3. 每一对共享 `pair_id`；图表用 `pair_id` 关联。
4. 不同周期的 `pair_id` 命名空间隔离（前缀 `S-` / `M-`）。

## 3. 触发算法（可复现）

### 3.1 短期买

同时满足：

- `MA5` 上穿 `MA10`（当日金叉）
- `RSI ≤ 72`（避免极端追高；允许超卖区金叉）
- 当日成交量 ≥ 近 10 日均量 × 0.85（排除明显缩量假突破）

### 3.2 短期卖（对应未平仓短买之后）

最短持有 3 个交易日，之后满足任一：

- `MA5` 下穿 `MA10`
- 或 `RSI` 自 ≥70 回落
- 或自买点后峰值回撤 ≥ 3.5%

### 3.3 中期买

满足其一：

- `MA20` 上穿 `MA60`；或
- 收盘收复 `MA20` 与布林中轨，且 `MA20` 斜率转正，同时 MACD 柱/ D-DEA 金叉转向

### 3.4 中期卖

最短持有 8 个交易日，之后满足任一：

- `MA20` 下穿 `MA60`
- 或收盘跌破布林中轨且 MACD 柱转负
- 或自买点后峰值回撤 ≥ 7%
